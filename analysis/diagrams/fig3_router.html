Router Decision Flow — map-stibo-inbound-validate-transform
Entry point router.lambda_handler(event, context) — every EventBridge S3 ObjectCreated event
Phase 1 · Event Ingestion
1Receive EventBridge event; log full JSON payload
2Parse detail.bucket.name and detail.object.key; URL-decode with unquote_plus
↓
Phase 2 · Path Gate
3Key outside raw/metadata/ and not a root global file? → respond 200 Ignored (no processing)
Global file (directly under raw/metadata/)
Detected via path depth = 3 or name contains “mdd” / “master data” / “attribute” → fan-out mode: loop over all 27 brands with a synthetic key raw/metadata/{brand}/.__global_trigger__, one AuditLogger per brand, isolated try/finally per brand
Brand-specific upload
Normal path → continue to Phase 3; single handler invocation for the detected brand
↓
Phase 3 · Brand Routing
4extract_principal(key) → path segment index 2 (e.g. raw/metadata/ellesse/file.xlsx → ellesse)
5Lookup BRAND_ROUTER[principal] — 27 registered handlers (adidas, new-balance, smiggle, aldo, diadora, crocs, 2xu, lotto, onr, nike, dr-martens, staccato, birkenstock, pazzion, clarks, steve-madden, asics, ptp, implus, astec, airwalk, ellesse, k-swiss, reebok, anta, new-era, anta-1)
Handler found
Route to {brand}.lambda_function.lambda_handler(event, context, auditor)
No processor configured
Respond 400 "No processor configured for brand" — upload stays unprocessed in S3
↓
Phase 4 · Handler Execution (isolated)
6Create one AuditLogger with router context: trigger type, original key, detected brand, routing decision
7Invoke handler inside try/except; exceptions captured as statusCode 500 + set_lambda_status("error")
⚠ Known defect (see Chapter 13)
Some ETL modules call sys.exit(1) — SystemExit is not an Exception subclass, so it bypasses this except block and terminates the whole invocation, including the remaining brands during global fan-out.
↓
Phase 5 · Audit Flush (always, in finally)
8auditor.flush(brand) → structured JSON to raw/logs/{brand}/{YYYYMMDD_HHMMSS}.json with request id, duration, and full execution evidence
9Return composite result (fan-out mode returns per-brand status map)
