Reference Data & Mapping Framework
How Excel reference workbooks flow into the ETL and shape every STEPXML value
SOURCES — Excel reference files (S3 raw/metadata root)
Master Data Dictionary (MAA).xlsx 87 sheets
Core Attributes: 401 rows · 380 distinct AT_ IDs · 40 metadata columns · cardinality 173 mandatory / 215 optional; 64 LOV sheets ≈ 43,352 entries (Vendor 32,663 · Size Code 5,061 · Franchise 1,917)
NEW — Brand mapping files Template.xlsx 58 sheets
29 brand tabs × 234 attribute rows · columns: AT_ id (VLOOKUP), validation, cluster, mapping type, source file/sheet/field, mapping logic, applicability letters A–F · 15 MD-Mapping value-translation tabs ≈ 1,700 pairs
Attributes List (per release)
Global attribute inventory uploaded at raw/metadata root; triggers fan-out refresh
Source Mapping related RNA 2,364 rows
Master lookup: country → company code → SBU → brand group / brand code / BY code
LOADERS — parsed inside the Lambda (per brand)
MDDLoader ×64 copies
Reads Core Attributes (header row 2) + every sheet named *LOV*; builds attribute metadata + display→ID lookup maps
AttributesListLoader
Reads brand tab of the Attributes List (e.g. “Ellesse(Inline + Licensed)”) to know which attributes to emit
AttributeMappingLoader newest
Reads brand tab of the mapping Template (ANTA, Birkenstock, Clarks, New Era, Reebok): mapping type Direct / Formula / Mapping → include; Manual / AI → exclude
MDMappingLoader per brand
Value translation tables: raw source value → Stibo display value → LOV ID (often one→many, e.g. JUNIOR → Gender Unisex + Age Children)
RNALoader ×37 copies
4-pass fuzzy join on brand/country; resolves SBU, company code, brand group, BY codes
CONSUMERS — per-article transformation
Attribute resolution
Source column → transform (substring, concatenation, price math, date reformat) → Stibo value
LOV validation & ID resolution
Display value → LOV ID written into <Value AttributeID="AT_x" ID="LOV_y">; miss policy varies: skip / raw-text fallback / default
Defaults & derivations
Country defaults (RNA), first-entry-as-main-vendor, ingestion-stage conditionals (1st vs 2nd), generic/variant code formulas
Mandatory checks
Cardinality = mandatory & value empty → warning recorded (article still written)
